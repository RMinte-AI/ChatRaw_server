# ChatRaw Server v0.0.1（待发布）

这是 ChatRaw Server 首个工程版本的候选发布说明。当前尚未创建 GitHub Release，Docker Hub 也没有 `0.0.1` 或 `latest` 标签。

## 主要能力

- 登录前不可访问业务功能或数据；
- 管理员与普通用户权限分离，所有用户共享同一平台数据；
- 普通用户可以使用已启用且角色允许的插件和模块功能，但不能安装、停用或删除；
- 独立后端模块通过 Module Protocol v1 接入；
- 模块功能的前端入口可由 ChatRaw 配套插件或随 Server 源码构建的 Resident Integration 提供；
- 支持模块任务、SSE、取消、审批、产物和 Host Capability；
- 支持经典 ChatRaw 数据只读导入、停机备份、校验和空目录恢复；
- 支持源码与 Docker Compose 部署；
- Agent 已作为首个按通用协议完成工程验收的模块适配，同时保留 Agent–LinkDB 私有协议。

## Docker 镜像（发布后）

```bash
docker pull massif01/chatraw-server:0.0.1
```

正式发布工作流必须验证同一个镜像 manifest 包含：

- `linux/amd64`
- `linux/arm64`

稳定版验证成功后同时发布：

```bash
docker pull massif01/chatraw-server:latest
```
