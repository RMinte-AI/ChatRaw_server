# ChatRaw Server v0.0.1

ChatRaw Server 的首个正式工程版本。

## 主要能力

- 登录前不可访问业务功能或数据；
- 管理员与普通用户权限分离，所有用户共享同一平台数据；
- 普通用户可以使用已启用的插件和模块，但不能安装、停用或删除；
- 独立后端模块通过 Module Protocol v1 接入；
- 模块的前端入口只能由 ChatRaw 配套插件提供；
- 支持模块任务、SSE、取消、审批、产物和 Host Capability；
- 支持经典 ChatRaw 数据只读导入、停机备份、校验和空目录恢复；
- 支持源码与 Docker Compose 部署；
- Agent 已作为首个正式模块完成全链路接入，同时保留 Agent–LinkDB 私有协议。

## Docker 镜像

```bash
docker pull massif01/chatraw-server:0.0.1
```

同一个镜像 manifest 包含：

- `linux/amd64`
- `linux/arm64`

稳定版同时发布：

```bash
docker pull massif01/chatraw-server:latest
```

## 验证边界

本版本已完成本地工程门禁，包括 Server 回归测试、双角色真实浏览器、
Source/Compose、模块故障、备份恢复和 Agent 全链路。客户真实数据、Token、
硬件、网络、DNS/TLS、防火墙、上游 API、生产规模、正式切流和回滚演练仍为
`PENDING_ONSITE`。

---

This is the first engineering release of ChatRaw Server. It introduces mandatory
authentication, admin/member roles on a shared platform, independent backend
modules connected through Module Protocol v1, plugin-only frontend integration,
task/SSE/approval/artifact contracts, classic-data import, verified backup and
restore, and Source/Compose deployment.

The Docker image `massif01/chatraw-server:0.0.1` contains both `linux/amd64` and
`linux/arm64`; stable releases also update `latest`. Customer data, credentials,
hardware, networks, upstream services, production scale, traffic cutover, and
rollback rehearsal remain `PENDING_ONSITE`.
